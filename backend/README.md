# Model Bot

This is the bot for the Model project. It is a Discord bot that serves the AI model by fetching predictions from the API.

## Installation for development

1. Install Yarn if you haven't already.
2. Run `yarn install` in the `bot` directory.

## Makefile Actions

- `build:docker`: Build the Docker image.
- `run:docker`: Run the Docker container.

## NPM Scripts

- `start`: Start the bot in production mode.
- `start:dev`: Start the bot in development mode.
